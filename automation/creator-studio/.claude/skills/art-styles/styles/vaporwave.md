# Vaporwave

Late-80s and 90s nostalgia: sunset gradient, striped sun, neon grid floor, Windows 95.

Reference tiles: `vaporwave` in `remotion/src/lanes/styles/StyleSheet.tsx` (a headline, a chat and a stat). Build from them.

- **Colours:** Night `#1a0033`, purple `#5b1a8a`, pink `#ff6ad5`, orange `#ffb86c`, neon grid `#ff3fd2`, cyan `#7ff9ff`, Win95 grey `#c0c0c0`, title bar `#000080` to `#1084d0`.
- **Type:** Unbounded for headlines (white with a pink offset shadow), Monoton for spaced-out labels, chrome gradient text for one big number.
- **Shapes and texture:** The `Sunset` scene (sun with mask stripes, perspective grid), Win95 windows with bevel borders for any UI.
- **Motion:** The grid scrolls toward the viewer; slow, dreamy fades.
- **Use for:** Nostalgia, "the old way" versus now, a fun end card.
- **Avoid:** Text over the sun (it gets lost: keep headlines above it); anything urgent.
