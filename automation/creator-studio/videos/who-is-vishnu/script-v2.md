# Who is Vishnu, take 2 (talking points, Vishnu improvises)

1. HOOK (A opens). Start straight in, no "hi guys": "I built six apps this year. Only one of them makes
   money." Then: "And I know exactly why the others died."
2. WHO. "I'm Vishnu, I'm 22." One line on what you build: mobile apps, web apps, Chrome extensions,
   AI products. The one that works has over 2,500 users.
3. PROOF. The one credibility line you'd say to a founder: you run an AI agent in the real financial
   markets that people trust with their money, so you know the guardrails that keep an agent from making
   wrong decisions in production.
4. THE ANSWER (A closes). "What killed the others was me." Built on the side next to the nine to five,
   and the moment an idea went quiet, moved on to the next one. None of them got enough time.
5. THE CHANGE. "So this time it's one product, in public, every day." Then AskVerb, clearly: it gives a
   SaaS product its own AI agent that does things for its users, so they don't dig through menus.
6. THE GOAL (B opens, stays open). First ten paying customers. "Right now that number is zero." End on:
   "Follow along and see if I get there."

Keep it under about 45 seconds. If you stumble, say the line again from the start of that beat, the last
take wins.
