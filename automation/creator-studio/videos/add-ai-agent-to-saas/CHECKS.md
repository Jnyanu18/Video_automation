# Checks: How long it takes to add an AI agent to your SaaS

Talking-head lane. Tick a stage (change [ ] to [x]) only after watching or reading its file. A stage
does not run until the one before it is ticked.

- [x] 0 Brief: brief.md, with at least one of purple-cow or story-loops
- [x] 1 Script: script.md, read aloud once
- [x] 2 Raw: ingest.md, every take is there, sound is clean
- [x] 3 Words: transcript.md
- [x] 4 Cut: work/cut.mp4 watched in full, cuts.md as wanted
- [x] 5 Edit: work/preview.mp4 and work/contact-sheet.png
- [x] 6 Render: out/, title and thumbnail picked
