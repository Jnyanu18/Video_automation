Do you use Claude Code inside Cursor? Check your extension right now.

On October 29 a poisoned update went out under the real Claude Code extension in Cursor's marketplace. Version 2.1.313.

It hid an SSH key called svc-telemetry, set itself to run again on startup, and sent out your username, git email and the names of your API keys. Up to 5,000 people installed it.

The VS Code Marketplace version was clean.

Update to 2.1.314, delete that key, and rotate your secrets.

## YouTube Short

Title: Claude Code users in Cursor: check your extension now (2.1.313 backdoor)

Description:
A poisoned update to the Claude Code extension went out through Cursor's marketplace on October 29. Version 2.1.313.

It went out under the real extension ID. Cursor says the malicious version was not developed by Anthropic, and up to 5,000 people installed it. It added an SSH key called svc-telemetry to your authorized_keys, set itself to run again on startup, and sent out your username, git email and the names of your API key variables.

The VS Code Marketplace build was clean, according to OpenSourceMalware.

What to do: update to 2.1.314, delete the svc-telemetry key from ~/.ssh/authorized_keys, remove any startup task it added, and rotate your secrets.

Source: https://thehackernews.com/2026/10/official-claude-code-vs-code-extension.html
