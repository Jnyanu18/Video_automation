# Reference atlas: eleven supplied videos

IDs follow upload order, not alphabetical filenames. Analysis used ffprobe metadata, one-second overview frames throughout every file, denser 0.25-second samples around selected transitions, scene-change candidates, decoded audio levels, and an unverified local speech-recognition pass. Visible behavior below is observed; software choice, easing values, and implementation methods are reconstruction recommendations. An MP4 does not reveal the original source code.

Time ranges are approximate visual segments, not frame-accurate cut annotations. Dense samples locate changes to about 0.25s; a transition may span that boundary. Automated scene detection missed many UI morphs and flagged some bright wipes as multiple cuts, so its scores are NOT an authoritative edit list. Audio measurements establish track presence/levels; no human listening pass or sound-source separation was performed.

See `reference-metadata.json` for machine metadata and `contact-sheets/` for the inspected visual evidence. The original MP4s are intentionally not redistributed in this package.

## What transfers across the set

1. A recognizable object or baseline often bridges scenes more effectively than an unrelated transition preset.
2. Detail sequences lead to simpler big type/numbers, then a settled identity close.
3. Motion attention is staged: hero action first, secondary text next, decoration last.
4. Product demos use longer holds than motion-reel accents. The 54s and 40s references are useful evidence for slower teaching/storytelling.
5. Repeated motion is phase-shifted rather than independently random.
6. Branding and photography remain asset-dependent; the skill should transfer technique without silently reusing another company's identity.

The parameter values in `motion-recipes.md` are recommended reconstruction settings, not extracted keyframes.
