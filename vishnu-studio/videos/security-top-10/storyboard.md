# Storyboard: Five security repos for Claude Code, ranked

Look: our own theme. Black, dark liquid glass cards, gold for the number that matters, one banner chip per station, one camera ride
from station to station (the Harvey pattern), Ava big at the bottom acting every line. Vishnu, 2026-11-03: "I want it to be our
own theme, this is like the reference video", so the first take (pastel cards, pixel noise) was dropped. What is kept from
research/viral/Dew5OaVgfmG is the idea only: a countdown, a star counter that ticks up, a rank bar, a mystery number one.
He also asked for real repo images: every card shows the repo's own GitHub page (dark theme, captured 2026-11-03), full width with
no frame, shadow or rounded corner, then a small scene wipes over it that plays what the repo does. The scenes borrow the grammar
(never footage) of three Lemo-Opuscar film styles: Hologram HUD, Visual Investigation, Countdown.

Each beat says what happens and what changes.

Through-line: the rank bar at the top (5 4 3 2 1) fills as the cards pass; the gold star counter on every card; the hidden number one comes back last.

Examples: the code line in No. 5 and the skill file in No. 3 are examples, labelled EXAMPLE on screen. The star counts are the
GitHub API's values on 2026-11-03 and will be rechecked on the render day (the repo pages show them rounded: 6.7k, 8k, 24.1k, 35.5k,
57.7k, so a recapture the same day keeps them in step). Phase names come from the Cloudflare README.

Ava: present, wow (over fifty-seven thousand), point-left (number five), think (four), shock (three, the bad skill), wow (two),
cheer (number one), wink (independently verified), wave (comment). Nine poses.

Sound: swipe at each ride, ding when a flaw is flagged, three clicks on the checklist, a stamp on BLOCKED and on VERIFIED, sparkle
on NIST, snap on the reply.
