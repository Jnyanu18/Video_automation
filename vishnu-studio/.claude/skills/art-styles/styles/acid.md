# Acid graphics / Brutalist web

Two moods in one: rave-flyer acid green on black, and raw unstyled HTML (Times, blue links).

Reference tiles: `acid` in `remotion/src/lanes/styles/StyleSheet.tsx` (a headline, a chat and a stat). Build from them.

- **Colours:** Black `#0A0A0A`, acid green `#C6FF00`; for the raw-web side white, black, link blue `#0000EE`, visited purple `#551A8B`.
- **Type:** Syne 800 stretched tall (`scaleY(1.4)`), Space Mono for system text, Times New Roman for the raw web.
- **Shapes and texture:** Outline words, barcodes, starbursts made of lines, `///` system labels, `<hr>` rules.
- **Motion:** Glitchy: hard jumps, stretches, quick flashes.
- **Use for:** Edgy hooks, no-nonsense or developer-facing points.
- **Avoid:** Stretched type is taller than its box, so size it down or it overflows the frame; a soft message.
