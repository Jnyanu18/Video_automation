```
The checklist:

1. System prompt: a name, a tone, and what it should never do
2. Your docs: it reads them before it answers, and says where the answer came from
3. Tools: Slack, Jira, HR, only the actions it really needs
4. Permissions: it sees only what the person asking is allowed to see
5. Guardrails: block "ignore your instructions" on the way in, hide private data on the way out
6. Cost: cache repeat questions, send easy ones to a small model
7. Logs: every prompt and tool call, so you can see why it got something wrong
8. Tests: a set of real questions with the right answers, run before every model or prompt change. No pass, no ship.
```
