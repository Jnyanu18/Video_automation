## Instagram

How do you make animated films without paying for an AI video tool?

Someone put the answer on GitHub, and it's free. It's called Lemo-Opuscar, it's MIT licensed, and it has over 11,000 stars after about five weeks.

It has 66 film styles, and Claude drew and scored every film by writing code. Pick a style like crayon picture book, watercolor or ink wash, tell it your story, and Claude directs the rest.

You install it with two commands, and it's tuned for Claude Opus 5.5.

## DM reply for the comment REPO

Here's the repo: https://github.com/lemomo-ai/lemo-opuscar

To install it, run these two commands in your terminal:
claude plugin marketplace add lemomo-ai/lemo-opuscar
claude plugin install lemo-opuscar@lemolab

It needs Node 20+, ffmpeg 7+ and Python 3.11+, and the styles are tuned for Claude Opus 5.5. The gallery of all 66 styles is here: https://lemomo-ai.github.io/lemo-opuscar/
