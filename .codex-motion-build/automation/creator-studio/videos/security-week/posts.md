Four things broke this week. Here's what to update, rotate and restart today.

Day 23 of 30, building in public.

Node.js shipped fixes for four high-severity bugs on 21 October, and one of them lets attackers run code on your server. Run at least 22.23.4, 24.22.1 or 26.12.1.

Then restart everything: a running app keeps the old version in memory until it restarts.
