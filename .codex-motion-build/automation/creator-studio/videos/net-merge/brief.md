- **Facts and sources (README of github.com/rohit267/net-merge, read 2026-11-07; the numbers are the developer's own):**
  free, open source, MIT, 2.9k stars; Windows, macOS, Linux (Android in beta); combines Wi-Fi, Ethernet, mobile data and
  phone tethers; the developer's test: Wi-Fi, an Android USB tether and an iPhone hotspot, nine downloads at once,
  232-303 Mbit/s, the fastest link alone about 121 Mbit/s; no proxy setup, no account, no server, no VPN; a tray icon,
  green while merging, grey when paused, shows each connection's speed and the total; one connection uses one link, so it
  helps parallel downloads; needs two or more independent connections; admin rights on Windows, installers not yet
  code-signed; a VPN on the computer can stop any gain.
