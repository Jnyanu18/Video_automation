# Original demo audio

The WAV and Python synthesis source were authored for this procedural motion example. Every oscillator, noise burst, drum and effect is synthesized locally from a fixed seed. No third-party song, reference soundtrack, downloaded recording or commercial sample was used. The source and output are included for editing/adaptation with the skill package.

The Inter and monospace fonts have their own licenses in `public/`; their terms remain separate. This note describes origin and usage, not a blanket license for external assets a host adds later.
