Agent Reach: let your AI agent read Reddit, YouTube, LinkedIn, Instagram, X and more

The repo (free, open source, MIT, over 106,000 stars): https://github.com/Panniantong/Agent-Reach

How to install it:
Paste this one line into your AI agent (Claude Code, Codex, Cursor and similar):
Install Agent Reach: https://raw.githubusercontent.com/Panniantong/Agent-Reach/main/docs/install.md
Your agent reads the guide and sets it up. Don't install the PyPI package called agent-reach: it is a different project.

What it reads: GitHub, YouTube and the web straight away. Reddit, LinkedIn and more when you add them. X, Facebook and Instagram are experimental: they work, but those platforms fight automation harder.

What to ask it:
1. Give it a link to any post and ask what people are complaining about.
2. "Find complaints about [competitor] on Reddit and YouTube."
3. "What jobs do people in [your niche] still do by hand?"
Then ask your AI to build on what it found.

The 2 crucial things to know before you install it:

1. Install its browser extension during setup. The setup step prepares a dedicated extension and connection. Skip it, and searches fail with a NEED_SETUP error. If something breaks, ask your agent to run: agent-reach doctor --text

2. Use a spare account. Platforms that need a login use your account, usually your main one, and platforms may restrict accounts used for automation. Log in with a secondary account instead.
